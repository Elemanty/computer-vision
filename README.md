# Computer Vision: обнаружение, отслеживание и Re-ID людей

Pet-проект по компьютерному зрению для обнаружения людей на видео, отслеживания их перемещений и сопоставления треков между разными видеозаписями.

## Цели проекта

- Обнаруживать людей на видео с помощью YOLO.
- Отслеживать обнаруженных людей между кадрами с помощью ByteTrack.
- Извлекать изображения людей из видеозаписей.
- Получать векторные представления внешнего вида людей с помощью OSNet.
- Сравнивать треки между двумя видео по косинусному сходству признаков.
- Находить наиболее похожие пары треков из разных видеозаписей.

## Используемые технологии

- **Python** — основной язык разработки.
- **PyTorch** — работа с моделями глубокого обучения.
- **Ultralytics YOLO** — обнаружение объектов.
- **ByteTrack** — отслеживание объектов между кадрами.
- **Torchreid / OSNet** — извлечение признаков для повторной идентификации людей (Person Re-Identification).
- **OpenCV** — обработка видео и изображений.
- **NumPy** — обработка векторов признаков и вычисление сходства.

Проект рассчитан на запуск на CPU. Для выполнения экспериментов не требуется отдельная видеокарта, хотя обработка на CPU может занимать больше времени.

## Как работает проект

### 1. Обнаружение людей и отслеживание

YOLO обнаруживает людей на каждом кадре видео. ByteTrack использует обнаружения на последовательных кадрах, чтобы связывать их в треки.

Каждому треку присваивается идентификатор. Он помогает отслеживать человека внутри конкретного видео, но сам по себе не является постоянным идентификатором личности.

### 2. Извлечение изображений людей

Из кадров видео извлекаются области изображения, содержащие людей. Изображения сохраняются в отдельных папках в соответствии с видео и идентификатором трека.

Это позволяет использовать полученные изображения для дальнейшего анализа внешнего вида.

### 3. Извлечение признаков с помощью OSNet

OSNet преобразует изображение человека в числовой вектор — embedding, описывающий визуальные характеристики изображения.

Для одного трека признаки нескольких кадров нормализуются и усредняются. Таким образом формируется обобщённое представление трека.

### 4. Сопоставление треков между видео

Для каждого трека первого видео вычисляется сходство с треками второго видео.

Используется **cosine similarity** — косинусное сходство векторов признаков. Чем ближе значение к 1, тем ближе направления нормализованных векторов.

По результатам сравнения формируется ранжированный список наиболее похожих пар треков.

## Установка и запуск

Проект разработан и проверяется в окружении Windows с использованием CPU.

### 1. Клонирование репозитория

```bash
git clone https://github.com/Elemanty/computer-vision.git
cd computer-vision
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация окружения в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```bash
python -m pip install ultralytics opencv-python numpy torchreid gdown
```

PyTorch необходимо установить отдельно, выбрав подходящий вариант для своей системы на официальном сайте: https://pytorch.org/get-started/locally/

### 4. Подготовка данных и моделей

Поместите входные видео в папку `videos/`.

Файлы весов моделей необходимо скачать отдельно и расположить по путям, которые ожидают соответствующие скрипты. В частности, скрипты используют YOLO и OSNet.

Большие видео, извлечённые изображения и файлы весов моделей не включаются в Git-репозиторий.

### 5. Запуск скриптов

Команды выполняются из корневой папки проекта:

```bash
python src/check_videos.py
python src/detection.py
python src/extract_person_crops.py
python src/test_reid.py
python src/compare_tracks.py
```

Скрипты предназначены для последовательного выполнения этапов проекта. Для корректной работы следующих этапов необходимо предварительно подготовить входные видео, результаты обработки и необходимые веса моделей.

## Ограничения

- Высокое косинусное сходство не доказывает, что на двух видео изображён один и тот же человек.
- Результаты зависят от освещения, ракурса, качества изображения, одежды и перекрытия объектов.
- Идентификаторы ByteTrack действуют в рамках конкретного запуска отслеживания и не предназначены для сопоставления личностей между независимыми видео.
- Для объективной оценки качества Re-ID необходим набор размеченных пар и подходящие метрики.
- Проект является учебным экспериментом и не предназначен для использования как готовая промышленная система.
